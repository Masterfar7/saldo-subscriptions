# Сальдо

«Сальдо» помогает вести список регулярных платежей и видеть ближайшие списания. Главная страница показывает среднемесячную нагрузку, годовой прогноз и сумму списаний на семь календарных дней, включая сегодня.

- Добавление, редактирование, удаление и поиск подписок.
- Ежемесячные и ежегодные платежи в рублях.
- Перенос платежа на последний день короткого месяца с сохранением исходного дня для следующих месяцев.
- Локальное хранение данных в браузере. При первом запуске показаны три примера, которые можно изменить или удалить.

## Запуск

Из каталога проекта выполните команду с Python 3 и откройте [localhost:8080](http://localhost:8080).

```bash
python -m http.server 8080 --bind 127.0.0.1 --directory dist
```

Интерфейс написан на HTML, CSS и JavaScript ES modules. Каталог `dist` можно разместить на статическом хостинге без сборки. Файлы `dist/app.mjs` и `dist/model.mjs` отвечают за интерфейс и расчёты соответственно.

## Проверка
